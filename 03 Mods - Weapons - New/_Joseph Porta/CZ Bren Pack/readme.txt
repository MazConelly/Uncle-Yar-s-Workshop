-Module:
CZ Bren Pack [Joseph Porta]
https://www.moddb.com/mods/stalker-anomaly/addons/cz-bren-assault-rifle-pack-v10

----------------------------------------------------------
-Compatibility:

You can skip the original patches and options, except for the non vanilla scopes ones (as I haven't worked on them yet).

----------------------------------------------------------
-Explanation:

Main files work both with the DX8-9 and DX11 packages.

NPC distribution. Changed inexistent ranks for veteran ranks, who will only have half a chance to spawn with these weapons than masters.
Trader distribution. Fixed Meeker file.

Weapons and vanilla scopes realigned for 3D ballistics.
Icon file trimmed.

Vanilla scopes, actor effects, parts, Grok's Enhaced Recoil, and Mags Redux files integrated.
Yeah, the first three are offered by the installer as optional and "Gamma files", which is kinda dumb, because, you know, *VANILLA USES ALL THAT AS A DEFAULT*. And who's gonna say no to being able to use the vanilla scopes? :V

Integration into:
FireModeCheck
Grok's Stash Overhaul
Lootboxes
PDA Interactive
Weapon Parts Overhaul

----------------------------------------------------------
-Patches:

3DSS files reworked for:
	Vanilla scopes

Now these you can let them overwrite the DX11 files.

M203 Grenade launcher
The original files, but consolidated.

Sound performance patch
If you feel the audio causes a performance drop, try this patch that reduces the audo layers, and see if it helps.
