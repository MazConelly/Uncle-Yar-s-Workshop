-Module:
Saiga-23 [ATHI]

----------------------------------------------------------
-Compatibility:
NOTE: You still need the original mod. Disable the gamedata/configs folder.

----------------------------------------------------------
-Explanation:

Internal ID renamed to not overlap with other existing Saiga bullpups and better identify the weapon as 23x75.
If you're running a game with the original mod, either wait to a new game to apply this module. But you can sidestep this by using the "12 gauge variant" files below.

Made the Saiga-23 a bit heavier, rarer, and more expensive.

Trader distribution.

Integrated into:
FireModeCheck
Grok's Stash Overhaul
Lootboxes
PDA Interactive
Weapon Parts OVerhaul

----------------------------------------------------------
-Patches:

12 gauge variant
Variant chambered for 12 gauge. Lighter, cheaper, more common.
It can be used standalone without the main files of this module, for example if you like the model and animation of the mod but don't want to bother with BaS and its 23x75 ammo.
Do note that any already spawned Saiga-23 in a save game will turn into this clone, so you may want to wait for a new game to install this patch. Otherwise, if you don't have one in your inventory, consider it an added form of progression.
Compatibility notes:
-If you're using Misc. Weapon Pack, make sure to load this on top.
-If you're using "Hisalute's Weapon Packs - Fixes and Tweaks", deselect the Saiga bullpup during install.
In both cases you should be able to continue a running game without other issues than the swap mentioned above.
-If you're using the "Fix And Rebalance of Weapon Stats" mod, do not use the "ATHI Saiga 23" patch, as it is intended for the Saiga-23's original files.

Sound performance patch
Use this to reduce sound layers if shooting the gun affects performance.

23x75 silencer safety
The Saiga-23 uses BaS' Swine silencer for 23x75 gauge. If you use my Vanilla silencer patch in this package or in BaS Lite, it will get assigned the Salvo instead.
This patch will ensure it keeps using the Swine.
Don't use it with the 12 gauge clone patch, as it won't have that issue.
Redundant with the BaS Lite option to keep the Swine silencer, as it will ensure this weapon keeps using that silencer.
