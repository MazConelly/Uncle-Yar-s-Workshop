-Module:
PSG1A1 [ATHI]

----------------------------------------------------------
-Compatibility:

NOTE: You still need the original mod. Disable the folders:
-configs
-textures/ui

IMPORTANT: If you were already running a game with this mod, you must wait to a new game before applying this module.

Misc. Weapon Pack. Several files overlap in both mods, despite offering different variants of the PSGA1.
This module reworks the configs files, but not the models, as that would inflate the package's size quite a bit. The model of one would take precedence over the other's.
"Hisalute's Weapon Packs - Fixes and Tweaks" reworks both the configs and models of MWP's PSG1, and so it's recommended for full compatibility. Just make sure to have ATHI's PSG1 load on top of the original MWP.
