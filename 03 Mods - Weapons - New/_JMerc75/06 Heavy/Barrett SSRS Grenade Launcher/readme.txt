-Compatibility:
NOTE: You still need the original mod. Disable the original configs folder.

----------------------------------------------------------
-Explanation:

Added "Barrett SSRS Grenade Launcher" as long name. "SSRS" remains as short name.
Upgrade wise, it uses the PM and TT33 upgrades and PM scheme. I changed it to use those of the Protecta. This means you eventually may have automatic fire.

In addition to Nimble, mercs, Monolith and ISG can also sell it, but they will only rarely have it on stock.

Icon file trimmed.

Integration into:
PDA Interactive

----------------------------------------------------------
-Patches:

Boomsticks and Sharpsticks 30-VOG ammo
The Barret SSRS, as far as I can find, uses 30mm grenades. It has assigned the Vog-25, which are 40mm, and the M203 are so as well. The Vog-30 in BaS are 30mm though, so we can use that instead.
BaS Lite allows installing only the Vog-30, if you're not interested in the rest of BaS.
