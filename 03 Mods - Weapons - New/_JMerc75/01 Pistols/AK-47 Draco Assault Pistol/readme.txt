AK-47 Draco Assault Pistol [Jmerc]
https://www.moddb.com/mods/stalker-anomaly/addons/ak-47-draco-assault-pistol

----------------------------------------------------------
-Compatibility:
NOTE: You still need the original mod. Disable the original configs folder.

----------------------------------------------------------
-Explanation:

Identified as the Micro Draco, the smaller configuration of the main Draco (which has a longer, more AK-47'ish handguard). It will still use "Draco" as a short name.

In relation to equiping in inventory slots, the yellowish stockless Draco will be treated as a pistol, and the black one with stock as a SMG.

NPC loadouts. Removed from Freedom, and given to Duty. It is a Romanian weapon for a WP ammo, and Duty gets few enough mod weapons assigned to them. However, Duty will get the stockless one, while mercs will swap it for the stocked one. Veterans will also get it, instead of only masters, though with a reduced change.
As above, the version with stock will be added as a primary weapon, not a secondary.

Traders. Only Nimble, ISG and the Flea Market were trading it. Now Duty, bandits and mercs will do as well, and is removed from Nimble. However the goodwill requirement for both versions is raised.

Icon file trimmed.
