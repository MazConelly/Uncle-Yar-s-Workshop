----------------------------------------------------------
-Explanation:

Taken off Sid's inventory, given to Owl. Just so you don't start a new game at south and start cherry popping npcs. Might give it to Nimble instead later.

Mags Redux support: Added magazines with full world models and icons, that can be used with other .50 BMG weapons. A 7 rounds mag, and a 20 rounds drum.
Use of the .50 BMG Restoration in the folder "00 Vanilla - Weapons, ammo" of this package is recommended. Otherwise you'll load 12.7x55 rounds instead of .50 BMG.
If you use Lewdnatic's .50 BMG ammo pack, make sure to use the module for it  in the folder "02 Mods - Ammo - New" of this package.

Integration into:
FireModeCheck
PDA Interactive
Weapon Parts Overhaul

----------------------------------------------------------
-Patches:

Icon fix
Nothing to actually fix, just simply merges both icon files into one.
Use this instead of the original mod's non hq option.

Sound performance patch
Reduces the number of layers used, in case they cause lag for you when shooting.

Mags Redux Standalone
Adds magazines with full world models and icons, that can be used with other .50 BMG weapons.
Intended to be use .50 BMG Restoration in this same package, as it uses its basic settings to work (reuse and recycle, you know). Otherwise you'll be loading 12.7x55 ammo instead of the intended .50 BMG and things will get weird.

You still need from the original mod's directory:
gamedata\textures\wpn\wpn_50bmg_deagle\

All .dds and .thm files sharing these names fully or partly:
lewd_grip_mag
50bmg_drum

Either disable everything in the original mod except the textures folder, or make a new MO2 "mod" with this patch and those textures.
