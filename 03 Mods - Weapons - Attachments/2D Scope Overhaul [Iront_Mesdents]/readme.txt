	-DX8-9 support
	-16-10 ratio
	-Beef's NVGs always work except on scopes

	Cr3pis's SKS Carbine in the Zone

----------------------------------------------------------
-Explanation:

Ensured the text changes aren't overwritten by other mods.

Updated the bolt action descope script with weapons from Simple Weapon Pack, Mosin Trio, Arisaka, and JMerc's.

Split the main mod_system file, with the content modularized into smaller files. This is merely done for easier maintenance and development to help make patches for 2D Scope Overhaul.

Hence, support for vanilla and various mods has been modularized, so you can choose what you want, for example if you use 3DSS, but some mods aren't yet prepared for it.

-Patches:

Beef's NVGs always work except on scopes - Beef's NVGs Improved
Substitutes the original option, only for party_50's Beef's NVGs Improved.

BaS SKS Improved
Remake of the original patch. Trimmed redundant data.

BaS Howa 20 Improved
Use this whether you use IModeusI's original or ATHI's edit.

Mosin Trio [Kmack]
Requested by Rambito.
It makes that mod observe the PU scope changes by 2DSO, an assigns a proper aiming texture to the guns.

SKS Carbine in the Zone [Cr3pis]
Requested by Rambito
Allows Cr3pi's rework of the the basic SKS to use the PU scope, with appropiate aiming texture. Hacky, but it works.
