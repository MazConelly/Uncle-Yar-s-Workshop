Mags Redux
Adds a extended .357 magazine with 11 rounds capacity, with its own icon and model. It will be assigned to the modern and Nimble Desert Eagle variants.
Can be used standalone without the original mod.
Arsenal Overhaul Late Comers includes a patch for this mod, which has the same Mags Redux support. Don't use them together.
