-Module:
Armored Ghillie suit

Based on "Strelok's own Ghillie Suit", by Zorben

----------------------------------------------------------
-Compatibility:
Original mod not required.

If you were using the original mod, you need to start a new game before swapping.

Incompatible with the design of:
	sneakydud's Ghillie Suit overhaul
	JaggerVorog's Ghillie Rework
	crea's Ghillie as backpack with dynamic camouflage

----------------------------------------------------------
-Explanation:

Zorben's mod made a rare semi-unique guillie suit owned by Strelok, with the ballistics of an armored suit. This seemed like a half cooked execution.

The new ghillie is not "Strelok's" anymore. Now it's just a generic armored ghillie that solvent traders will have instead of only a few.
The mod gave it the the ballistics resistances of the CS-3, so it now also gets the same resistances and inmunities as it, a tad more concealing, but it's quite vulnerable and fragile against fire, and tires you faster.
It also gives the model for both ghillies proper protections for NPCs, as it lacked none. While there are no NPCs spawned with ghillie, you can still give them to a companion through mods.
It also gets parts assigned.

The vanilla ghillie moves down a goodwill tier in traders from 5/5 to 4/5, to leave space to the new one.
