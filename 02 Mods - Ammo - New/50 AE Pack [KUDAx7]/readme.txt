-Explanation:

Removed unrelated DLTX patch that could interfere with other mods.
Trade files fixed up where needed, and ammo redistributed; WP leaning factions won't sell the ammo, JSP and JGP rounds are one supply tier higher than before, and Explosive ones two tiers. Bandits will sell only the basic rounds. Basic Trader Profile Expansion support.
Texture compressed and mipmapped.
Icons made standard size as per vanilla. Check below for HD Icons Framework.

Integrated into vanilla looting, item manager, and treasure manager systems.

Integration into:
Arszi's Mutant Bleeding + Optimized Patch
Grok's Stash Overhaul
Lootboxes
PDA Interactive

-Patches:

HD Icons Framework
Now optional, for those who don't want to use HD Framework. Honestly, this should have been the default. However the lettering will be too hard to read.

AO3 Late Comers patch
The FMJ, JHP and JSP rounds are disabled, in favor of the Late Comers equivalent. This is due to Late Comers' having old and damaged variants, and removing them in a current save might cause a crash.
Its Mags Redux support will be used.
