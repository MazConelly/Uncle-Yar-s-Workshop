-Module:
Glocked Kriss mags (Mags Redux)

Original mod and author unknown. Files are found in:
	Pillii's Glock and RONI
	Yukizz's Kriss Vector Custom

You can otherwise find it by its ui_icon_krissmags.dds icon file.

----------------------------------------------------------
-Compatibility:

In addition to adding new mags, this will make changes in:
	Lewdnatic's Kriss Vector
	Nullpath_01's Kriss Vector
	Pillii's Glock and RONI
	Yukizz's Kriss Vector Custom

Make sure this module loads after all those mods.

----------------------------------------------------------
-Explanation:

A set of Kriss Vector magazines used by the two mods above (and whichever ones I may not be aware of), whose base type is set as "kriss". Understandable, but the issue being that if you don't have any mod adding a Kriss Vector in 9x19 or .45 ACP, they're just bloat only used for the RONI and Yukiz's Kriss. And as I understand Kriss Vector systems use the Glock magazine design. And Lewdnatic's Kriss uses the UMP45's mag base type. You do start seeing the problem, right?

This version of those mags changes the base type of the mags to Glock both for 9x19 and 45 ACP, using the Glock .45 ACP type from Pretty Pistols Pack, and assigns those types to the RONI carbines and the various Kriss Vectors around (Lewdnatic's, Yukiz's, Nullpath_01's).

This way, these Kriss mags and any Glock ones can be used by all both Kriss and Glock weapons, just like in real life.
