-Module:
Overly Large Magazines [MaidResidence]

----------------------------------------------------------
-Compatibility:
Original mod not required.

MrB's Extra Mags's is redundant.

If you use Misc. Weapon Pack, "Hisalute's Weapon Packs - Fixes and Tweaks" is recommended for compatibility with the overlapping magazines. However, please wait for it to update after today 7/22/26.

----------------------------------------------------------
-Explanation:

A collection of large magazines by Maid, that wasn't available in Moddb before, but some mods would use. It has been expanded with new magazines and others from other mods are also added, like MrB's Extra Mags, Old CW Pistol Pack and Misc. Weapon Pack.

Some tweaks and fixes have been made to internal IDs, names, descriptions, and mag qualities. For example, the pistol drums are treated as medium sized mags, not large.

All accounts for the following:
	- 5.56x45 extended casket (80)*, STANAG <-> AUG <-> FAMAS <-> G36 <-> SIG.
	- 5.56x45 CMag, STANAG <-> AUG <-> FAMAS <-> G36 <-> SIG.
	- 7.62x51 drum (50), hinge <-> STANAG.
	- 9x39 drum (50), Groza <-> Val/Vihr/VSS <-> VSK
	- AK drum (75), 5.45x39 <-> 7.62x39.
	- AK banana (100), 7.62x39.
	- AUG compact (20).
	- FN57 extended mag (30).
	- Glock extended mag (33), 9x19 <-> 9x18.
	- Glock drum (50), 9x19 <-> 9x18.
	- MP5 extended mag (40), 9x19 <-> 9x18 <-> .45 ACP.
	- MP5 drum (50), 9x19 <-> 9x18 <-> .45 ACP.
	- MP7 extended mag (60)**, 9x19 <-> 9x18.
	- MP7 compact mag (20), 9x19 <-> 9x18.
	- P90 extended mag (70)
	- PM drum (80), 9x18 <-> 9x19.
	- PM drum (84), 9x18 <-> 9x19, craftable***.
	- PPSH-41 stick (35)
	- RPK drum (75), 5.45x39 <-> 7.62x39.
	- RPK drum (95), 7.62x39.
	- RPK-16 drum (95), 5.45x39 <-> 5.56x45.
	- Saiga-12 drum (20).****
	- Vepr-12 drum (20).****
	- M249 big box (200)*****
	- PKM big box (200))*****
	- .50 BMG mag (7) and drum (20)******

*
Originally 100 rounds, but that feels too much for a casket, and the base casket is 60 rounds.

**
Originally 30 rounds, but the default MP7 mag loads 40 rounds, so where's the extension there? :_D

***
With 1 PPSH41 drum, 5 PM mags, and plenty of scrap, or 1 PM 80 round drum and a single piece of scrap. Compatible with Banjaji's Crafting System Improvements.

****
The Saiga and Vepr drums can be retooled between each other. They also were using a extended Saiga mag model. This model will be assigned to the base extended mag (which uses the model for the default mag), and the drums will use the USAS12 drum model.

*****
Are the big LMG ammo boxes needed? Not really. But there are 200 round boxes in real life, and this should still keep them as the real ammo hoses despite rifles getting 80-100 round drums.
Though I would like that players wouldn't be able to add them to their loadouts, 

******
The same ones from the same module in this package for Lewdnatic's .50 BMG Desert Eagles, only the text description changed for something less ridiculous. They can be used by the M82, and any other weapon sharing the same mag type.
Use of the .50 BMG Restoration in the folder "00 Vanilla - Weapons, ammo" of this package is recommended. Otherwise you'll load 12.7x55 rounds instead of .50 BMG.
If you use Lewdnatic's .50 BMG ammo pack, make sure to use the module for it  in the folder "02 Mods - Ammo - New" of this package.

Includes needed textures, so as to not be dependant from other mods (ie: BaS).

----------------------------------------------------------
-Patches:

Boomsticks and Sharpsticks
Made into its own module, as vanilla doesn't have a SKS using external magazines.
It includes:
- SKS drum magazine, 75 rounds, 7.62x39, retooled to 7.62x54.

Oiltanker's BaS Saiga 12s drum magazine kit
The improved Saigas will use the Saiga drum, not the USAS one.

4.6x30 Restorations
The MP7 mags will be patched to be chambered for 4.6x30 instead of 9x18, in case you restored that ammo, for example with Krepin's MP7 Reanimation.
